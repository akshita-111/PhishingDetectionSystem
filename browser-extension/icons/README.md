# Phishing Detection Extension Icons

This directory should contain the following icon files:

- icon16.png (16x16 pixels) - Small toolbar icon
- icon48.png (48x48 pixels) - Extension management icon  
- icon128.png (128x128 pixels) - Chrome Web Store icon

## Creating Icons

You can create these icons using:

1. **Online Icon Generators**:
   - https://favicon.io/favicon-generator/
   - https://www.favicon-generator.org/
   - https://favicon.io/emoji-favicons/

2. **Design Tools**:
   - Canva, GIMP, Photoshop
   - Use a shield, warning triangle, or lock symbol

3. **Simple Icons**:
   - Search for "phishing detection icon" or "security shield icon"

## Recommended Design
- Use red/yellow warning colors
- Include shield or warning symbols
- Keep it simple and recognizable at small sizes
